# Projects

Projects give related work a durable, organized home in Bionic. A project can keep a chat prompt, attachments, and conversation history together so ongoing work is easy to find and continue.

## Create a project

Open **Projects** from the Work navigation and select **New Project**. Give the project a short name, add any context or guidelines you want to retain in its chat prompt, and choose its visibility.

- **Private** projects are visible only to their creator.
- **Team** projects can be shared with members of the same team.
- **Company** visibility is available where an administrator has enabled it.

## Work in a project

Open a project to start a chat, review its existing conversations, or add attachments. Chats started from the project are collected in its history, making it possible to return to related work without searching through unrelated conversations.

The project page also stores its chat prompt and uploaded files alongside that history. You can edit the project or add and remove attachments as the work evolves.

## Delete a project

Deleting a project removes the project container and its project attachments. Existing conversations are no longer grouped under that project, so confirm that the saved project context is no longer needed before deleting it.
